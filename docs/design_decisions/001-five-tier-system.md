# Decision: Five-Tier Developmental System

## Status
Accepted

## Context

The original framework was preschool-only. To scale across ages, we needed to determine tier boundaries.

## Decision

Five tiers based on Piaget's cognitive stages and Kohlberg's moral reasoning:

| Tier | Ages | Piaget Stage |
|------|------|--------------|
| 1 | 3-5 | Preoperational |
| 2 | 6-8 | Early Concrete |
| 3 | 9-11 | Concrete |
| 4 | 12-14 | Early Formal |
| 5 | 15-17 | Formal |

## Rationale

**Against fewer tiers (3):**
- Misses critical Tier 2→3 transition
- Forces crude binary choices

**Against more tiers (7+):**
- Diminishing returns
- Adjacent years don't differ enough

**Why these boundaries:**
- Piaget stages are well-documented
- Each tier has distinct cognitive capabilities
- Tier 3 is natural inflection point

## Consequences

**Positive:**
- Clear, defensible boundaries
- Grounded in established science
- Distinct rules per tier

**Negative:**
- Some children develop faster/slower
- Five profiles to maintain

**Mitigation:**
- Profiles are configurable
- Tier 4 can be interpolated from 3+5
