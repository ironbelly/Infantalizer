# Contributing

## Ways to Contribute

### 1. Add Work-Specific Mappings

Most valuable contribution.

1. Copy `templates/work_mapping_template.yaml`
2. Place in `config/concept_mapping/templates/`
3. Complete all sections
4. Test with one chapter at Tier 1
5. Submit pull request

### 2. Improve Age Profiles

Based on research or feedback.

### 3. Enhance Prompts

Clearer instructions, better examples.

## Pull Request Process

1. Fork the repository
2. Create branch (`feature/your-feature`)
3. Make changes
4. Test
5. Submit PR with description

## Style Guide

### YAML Files
- 2-space indentation
- Comments for complex sections

### Markdown
- ATX-style headers (`#`)
- Fenced code blocks

### Naming
- Files: `lowercase_with_underscores.yaml`
